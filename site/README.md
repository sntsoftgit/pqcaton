# site — 공개 사이트

`site/` 아래가 그대로 GitHub Pages로 올라갑니다([워크플로](../.github/workflows/pages.yml)).
빌드 단계가 없습니다 — **정적 파일을 그대로 올립니다.** 정적 사이트 생성기를 두지 않은 이유는
하나입니다: 지금 페이지가 하나뿐이고, 도구를 먼저 들이면 그 도구를 관리하는 일이 먼저 생깁니다.

| 지금 | |
|---|---|
| [`index.html`](index.html) | 아키텍처 문서. 자립형 한 장 — 외부 요청이 하나도 없습니다 |

## 규칙

- **자립형으로 둡니다.** CDN 스크립트·웹폰트·원격 이미지를 쓰지 않습니다. 오프라인에서 파일을
  더블클릭해도 그대로 열려야 합니다.
- **라이트·다크 둘 다 그립니다.** 색은 `:root`의 토큰으로만 씁니다 — 미디어 쿼리 안에서만
  정의된 색이 있으면 한쪽 테마에서 글자가 안 보입니다.
- **저장소 문서로 거는 링크는 절대 URL**입니다. 사이트는 `site/`에서 서빙되므로 `../docs/…`가
  닿지 않습니다.

## 소개 홈페이지로 넓힐 때

`index.html`을 소개 페이지로 새로 쓰고, 지금 것을 `architecture.html`로 옮깁니다. 머리의
`<nav>`가 그때 쓰라고 미리 있는 자리입니다.

## 아직 켜지지 않았습니다

리포가 **private**인 동안에는 Pages가 유료 플랜에서만 열립니다. 공개로 바꾸고
**Settings → Pages → Source 를 「GitHub Actions」**로 두면 위 워크플로가 바로 배포합니다.
