# 규칙이 **잘못 잡는 말.** 재기 전에 같은 길이로 덮는다. 한 줄에 하나.
#
# RE2 에는 뒤보기가 없어서 「갈리는」 하나로 재면 「헷갈리는」이 함께 걸린다. 실제 문서에
# 그 자리가 여섯 곳 있었다. 잘못 잡는 관문은 예외 목록을 쌓게 만들고, 예외가 쌓이면 진짜
# 위반도 함께 묻힌다.
#
# **덮기는 자리를 밀지 않는다.** 같은 글자 수로 바꾸므로 줄 번호가 그대로다.
#
# 규칙표와 같은 이유로 코드가 아니라 여기에 둔다: tools/checktext 가 Go 문자열의 한글을
# 막고, 이 목록은 잘못 잡는 자리를 만날 때마다 늘어난다.

헷갈
헛갈

# 「머신 지문」은 이 제품이 쓰는 고정 용어다(machine fingerprint). 「가상머신」도 정착된 말이다.
# 둘 다 기계·머신 혼용이 아니므로 「머신」 규칙에서 뺀다.
머신 지문
가상머신

# 「게이트웨이」(gateway)는 별개 낱말이다. 「게이트」 규칙에서 뺀다.
게이트웨이

# 「영어는 그 사실을 가진 패키지가 갖고, 한국어는 화면 카탈로그가 갖는다」는 이 리포가
# 정한 규칙 문장이고 여러 곳에 그대로 인용된다. 「가진…갖고…갖는다」의 짝이 뜻을 만든다.
# 「갖다」 규칙에서 뺀다.
카탈로그가 갖는다
